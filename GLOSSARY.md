# FlexSpot FF

A fantasy football site where members play in Sleeper leagues and in a set of
side games that run alongside them.

## Games

**League**: A Sleeper league of member teams, scored head-to-head each NFL week.
_Avoid_: side game, contest, pool

**Side game**: A game on the Games page played alongside the leagues rather than
in one: QB Streaming, Spread Pool, Locks Challenge, DFS Survivor, F², Survivor
and Omni. _Avoid_: weekly game, mini game, side quest

**Side game week**: One NFL week's instalment of a side game, which may open for
entries and later be scored. _Avoid_: round, slate, matchup

**Open** (of a side game week): Available for members to enter, with its games
and picks in place. _Avoid_: started, published, live, unlocked

**Scored** (of a side game week): Its results have been written, and it can no
longer be entered or changed. _Avoid_: finalized, settled, closed, complete

**Auto-managed** (of a side game week): A week the automation owns because no
admin has acted on it. Any admin action hands the week to a human and ends the
automation's involvement. _Avoid_: automated, automatic, unmanaged

**Kickoff**: The moment an NFL game starts, when picks on that game lock.
_Avoid_: game start, game time, launch

## Schedule

**NFL week**: A numbered week of the NFL schedule, and what a side game week
mirrors. _Avoid_: calendar week, game week
